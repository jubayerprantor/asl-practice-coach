Using the Muscle-Memory Loop

Choose the artwork

Use the horizontal signature on lessons and headers. Use the stacked signature on narrow covers. Use the standalone loop when the product name is visible nearby.

Spacing and size

Leave at least one quarter of the loop’s diameter clear on every side. Start at 144 px wide for the horizontal signature and 100 px for the stacked signature. Use the simplified symbol below 32 px. Its minimum size is 16 px.

Colour

Slate charcoal #181B1E · RGB 24, 27, 30
Coaching amber #FFB020 · RGB 255, 176, 32
Eggshell #F6F6F3 · RGB 246, 246, 243

Use charcoal lettering on light backgrounds. Reserve amber for the hold arc. Use the mono artwork for single-ink printing and the white reverse artwork on dark fields.

Lettering and shape

The signature pairs Segoe UI Bold with Segoe UI Regular. The letters are vector outlines. Scale the entire SVG proportionally and keep the arc at the upper right. The hand is a brand illustration. Use reviewed instructional artwork when teaching hand position.

Web and app icons

Copy the icons folder to your site root and insert the links from head.html into the page head. Use the supplied 180 px Apple touch icon and 192 and 512 px manifest icons.
